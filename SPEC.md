# Sound-Out Speller — v1 Spec (pre-registered before training, 2026-11-18)

Picked by Rusty 2026-11-18 ("Create and start training the sound out speller") from the
CPU-trainable shortlist in the "CPU-trainable model ideas" chat. Discussion/spec context:
that chat's deep-dive on idea #6.

## Task
Given a child's phonetic misspelling of a word from a bounded early-reader vocabulary,
rank the vocabulary so the intended word is at (or near) the top, and identify which
spelling pattern broke (teaching layer, later demo step — v1 trains the ranker and a
deterministic pattern tagger for the *target* word's difference from the attempt).

- Bounded vocabulary v1: Dolch 220 service words + Dolch nouns (single-token only),
  ~313 words, levels pre-primer → third grade + nouns. See data/vocab.json + PROVENANCE.md.
- Input v1: typed attempt, one word. (Handwriting input via Write It Right is a later step.)
- Output: ranked top-5 candidates with scores; "leave alone" behaviour for correct
  spellings and out-of-vocab attempts is measured, not assumed.

## Model form (CPU by design)
Pair ranker: for (attempt, candidate) compute ~15 handcrafted features — Levenshtein
distance (raw and on a code-built phonetic "sound form"), char bigram/trigram Dice,
vowel-skeleton and consonant-skeleton distances, first/last letter and prefix/suffix
matches, length difference — and score with a logistic regression trained on
match / non-match pairs. Exported weights are a few KB; inference scores the whole
vocabulary per attempt.

## Training data (terms-safe, code only)
Misspellings are generated by `gen_v1_data.py`: deterministic, seeded phonics-error
rules applied to the vocabulary words (silent-e drop, vowel-team swaps, double-letter
errors, ck/k, c/k, wh→w, th→t/d, vowel swaps, unstressed-vowel drop, adjacent transpose,
y→i, er→ur, generic letter drop). No human data, no frontier-model output anywhere in
data, labels, scores, or filtering. Gemini Decision 1 may be used later as a benchmark
scoreboard only (Rusty's 2026-11-18 ruling), never as a teacher.

## Splits (seed 42)
- Instance split: per word, generated variants shuffled → train 70% / val 15% / test 15%.
  Words appear in all splits (the product premise is a *known* bounded vocabulary;
  unseen corruptions are the test).
- Family-held-out exam: corruption families `wh_w` and `er_ur` are excluded from
  training entirely and evaluated separately as an unseen-pattern exam.
- False-correction check: every vocabulary word spelled correctly is fed as an
  attempt; the model must rank the word itself #1.

## Baselines (trivial, must be beaten widely)
- B0: plain Levenshtein distance ranking.
- B1: phonetic sound-form Levenshtein ranking only.

## Gates for v1 (set before training)
1. Test top-1 ≥ 0.80 and top-3 ≥ 0.95.
2. Test top-1 beats B0 top-1 by ≥ 0.10.
3. False-correction: correct spellings rank themselves #1 ≥ 99% of the time.
4. Model file < 2 MB (expected: a few KB).
5. Family-held-out exam reported honestly (no pass gate for v1; it sizes the v2 problem).

If a gate fails, v1 is reported as failing with evidence — not shipped quietly.

## Amendment (2026-11-18, during v1 development — disclosed, not hidden)
Two design fixes were made after diagnostic runs against the development test,
so v1's test numbers are **development numbers, not a pristine locked-test
result**; v2 must be judged on a fresh exam (new generator seed, exam-only set).
1. **Identity training:** run 1 never trained on correct spellings, so the model
   learned a negative weight for "attempt == candidate" (it only saw that as a
   collision negative) and ranked correct spellings first only 13% of the time.
   Fix: correct-spelling training pairs for a seeded half of the vocabulary;
   the other half stays held out for the false-correction check.
2. **Exact-match runtime rule:** all remaining raw-model self-rank failures were
   homophone sets (to/too/two, there/three/their, read/red, ran/rain, off/of).
   The product ranker therefore trusts an attempt that exactly matches a
   vocabulary word and ranks it first by deterministic rule; the model ranks
   everything else. Raw-model metrics are reported alongside product metrics.

## Honest limits (v1)
- Dolch has almost no regular -ed past-tense words, so the -ed pattern family
  (jumpt/watched-type errors) is out of v1's vocabulary; it needs a pattern-word
  supplement in v2 from a separately sourced public list.
- Homophones (there/their, to/too) cannot be resolved from a single typed word;
  context is a later slice with its own gate.
- English only. Practice aid only — no dyslexia/therapy claims.
- Generated misspellings are rule-based approximations of real children's errors,
  not recordings of real children; accuracy here does not prove accuracy on real
  kids' writing. That claim needs a real (licensed/consented) corpus later.
